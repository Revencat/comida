# FRIDGIE 🥬

Tu cocina, siempre a mano. Web + PWA instalable, preparada para escritorio (Tauri).

```bash
cd fridgie && npm install && npm run dev     # desarrollo
npm run build                                # producción → dist/
```

Documentación completa de PWA, offline, iconos y empaquetado: `fridgie/docs/PWA-Y-ESCRITORIO.md`
